# Training Guide — Editors

Editors create and submit content for review.

## Logging in

1. Go to `/admin/login`.
2. Enter your email and password.
3. Complete MFA if it is enabled for your account.

## Creating a news post

1. From the admin dashboard, click **News → New**.
2. Fill in the Swahili title and body (`titleSw`, `bodySw`). English fields are optional.
3. Add a cover image key or attach a PDF document.
4. Choose a publish date or leave it as today.
5. Click **Save Draft**, then **Submit for Review**.

## Creating a vacancy

1. Click **Vacancies → New**.
2. Enter the title, MDA, and closing date.
3. Optionally add an external apply URL.
4. Attach any PDF advert or application form.
5. Save and submit for review.

## Creating an interview notice

1. Click **Interviews → New**.
2. Select the type: **Call for Interview** or **Interview Result**.
3. Add the title, MDA, and publish date.
4. Attach the PDF shortlist or results document.
5. Submit for review.

## Document attachments

- Only PDF, DOCX, JPEG, and PNG files are allowed.
- Each file is scanned by ClamAV before it is stored.
- If a scan fails, the upload is rejected.

## Tracking your submissions

- Use the dashboard link to view items you created.
- Wait for a reviewer email before a submission is approved or rejected.
